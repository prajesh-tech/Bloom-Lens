# Extraction fixtures

These internally authored sample papers cover five subjects, multiple sections,
printed numbering, parent/child labels, section allocations, alternatives, and
optional questions. Each JSON file specifies the exact extracted scoring fields
for its adjacent text file; expected results are not generated by the parser.

Optional rules are persisted in `validation_metadata.optional_details.rules`
as `{section, n, m}`. Selectable totals are computed only for complete sections
with equal main-question totals. Other optional structures remain uncertain.
Analytics expose `uncertain_paper_ids` when a choice-dependent distribution
cannot be determined. Counts describe available leaf questions, not a guessed
student selection. Overview marks use validated selectable totals where known.

Marks require an explicit marks suffix, parenthesized M, or trailing bracketed
number. Explicit allocation headings such as `Answer the following questions 2 x 5 = 10` remain supported for
compatibility; ordinary arithmetic and metre measurements are not allocations.
DOCX paragraph/table order is preserved. Page count is null when pagination is
not reliably known; the text is returned as one logical extraction block.
